# "How Does Generative AI Make Music?" — Inside YuE2-3B

An interactive, chapter-based educational React explainer designed for junior Python developers who want to understand how frontier music AI models work, built around **`m-a-p/YuE2-3B`**.

From typing a two-line lyrics prompt to outputting a full 48 kHz stereo song with singing vocals and acoustic accompaniment.

---

## 🎵 What This Explainer Covers

The app follows the complete 4-stage pipeline of **YuE2-3B**:

$$\text{Your Words} \longrightarrow \text{Plan (ABC Sheet Music)} \longrightarrow \text{Rough Draft (Semantic Tokens)} \longrightarrow \text{Acoustic Latents (Flow Matching)} \longrightarrow \text{Waveform (48 kHz Stereo Audio)}$$

1. **Foundations (Chapters 0–6)**: Tokens, vocabularies, high-dimensional embeddings, transformers, query/key/value attention, autoregressive sampling (temperature, top-k, seeds), and gradient descent training.
2. **Music Specifics (Chapters 7–11)**: Why raw audio explodes into 17+ million numbers, symbolic planning with ABC notation (`cot="full"` vs `cot="melody"`), semantic audio tokens, non-autoregressive flow matching, and VAE decoding into 48 kHz stereo sound waves.
3. **Synthesis & Control (Chapters 12–15)**: The unified AR–NAR Mixture-of-Transformers backbone, guided full-journey walk-through with GPU memory telemetry, cover song generation with SheetSage2, agentic score editing with LLMs, and phoneme error rates under the CC BY-NC 4.0 license.

---

## 🏆 The Golden Rules

Every chapter strictly adheres to the project's educational constitution:
- **G1: No unexplained jargon**: Every technical term is defined in plain words with a `<Term>` popover and indexed in the 65-term Glossary.
- **G2: Analogy first, mechanism second**: Every concept opens with an everyday analogy, followed by the mechanism and an explicit "where the analogy breaks" callout.
- **G3: Assume Python, not ML**: All mathematics is grounded in standard Python concepts (`dict`, `list`, `math.dist`, `random.choices`, loops).
- **G4: Honest toys**: All interactive simulations are explicitly labeled with `<ToyBadge>` ("Toy demo — illustrates the idea, not YuE2's actual numbers").
- **G5: One new big idea per screen**: Generous whitespace, short sections, and toggleable "Explain it simpler" (ELI5) paragraphs.
- **G6: Don't invent facts**: All architectural figures and numbers are verified against arXiv:2609.33757 and documented in `content/facts.ts`.
- **G7: End-of-chapter recap & quiz**: Every chapter concludes with a 3–5 bullet summary and a 3-question quiz with instant explanations.

## 🚀 Running the Project

```bash
# Install dependencies
npm install

# Start the Vite development server (port 3000)
npm run dev

# Build for production
npm run build

# Run TypeScript typecheck / lint
npm run lint

# Audit all glossary terms, chapter newTerms, and fact integrity
npm run test:glossary

# Execute and test all runnable Python snippets in Python 3
npm run test:python
```
